## What is Claude Motion

Claude Motion is a beta capability in Claude that lets a coding agent write and
render motion graphics directly from a prompt — you describe the animation, it
produces the code, then the video.

This list tracks what people are actually building with it, plus the prompt and
skill patterns that make results repeatable.

*Beta status changes quickly — if something here is out of date,
[open an issue](../../issues).*
